# Portfolio Website

This is my personal portfolio website showcasing my skills, projects, and experience.

## Website Structure

- `index.html` - Main portfolio page
- `projects.html` - Detailed projects page
- `timeline.html` - Learning journey timeline
- `styles.css` - Custom styling
- `PROJECT_DOCUMENTATION.md` - Technical documentation

## Deployment

This website is deployed using GitHub Pages. To set it up:

1. Go to repository Settings
2. Navigate to Pages section
3. Select "Deploy from a branch" 
4. Choose "main" branch with "/ (root)" folder
5. Save changes

The website will be available at: https://shashank666666.github.io/

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Design

## Local Development

To run this website locally, simply open `index.html` in a web browser.
